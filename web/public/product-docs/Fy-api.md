## 控制台
### 模型对话
&emsp;&emsp;这里可以快速进行 AI 聊天，方便测试和使用平台模型广场中的模型，点击分组下拉选择用户群体，用于区分不同群体的模型使用权限，便于后续权限与资源的分组管理。图片地址需开启开关后添加链接，可实现文本 + 图片的多模态对话（如让模型解析图片内容）。

+ Temperature（温度）通过滑块调整，数值越高输出越具随机性与创意（适合文案创作）、越低则越严谨聚焦（适合信息总结）；
+ Top P借助滑块控制词汇选择的集中性，数值越小输出内容越聚焦，避免发散；
+ Frequency Penalty（频率惩罚）通过滑块调高可减少内容重复，避免冗余表述；
+ Presence Penalty（存在惩罚）通过滑块调高可鼓励拓展新话题，避免对话局限于旧内容；
+ Max Tokens通过输入数值限定单次输出的最大 token 数（对应文本长度，1token≈0.75 个中文字）；
+ Seed（随机种子）可选填数值，使相同输入得到一致输出以复现效果（留空则为随机）；
+ 流式输出开启后，模型会输出结构化内容（如列表、代码块），适配需清晰排版的场景。

### 数据看板
&emsp;&emsp;在这里可以查看Fy-api的总体统计数据，可帮助用户实时掌握自身API调用的账户状态、资源消耗、运行性能与模型使用情况，以及系统公告和常见系统问答。

&emsp;&emsp;涵盖账户数据（可查看当前余额、历史消耗并执行充值操作）、使用统计（统计API请求次数等调用数据）、资源消耗（追踪额度与Token的消耗情况）、性能指标（查看平均 RPM、TPM等运行指标）及模型数据分析（通过图表展示模型消耗分布、趋势等）功能模块，点击进行刷选可按照不同时间单位区间查看不同模型的调用消耗数据。

&emsp;&emsp;平均RPM（每分钟平均API请求次数）和平均TPM（每分钟平均处理的 Token 总量）是核心的调用与资源消耗统计指标。其中平均 RPM 反映平台的请求并发压力，可用于指导服务器扩容、限流规则配置等运维决策，平均 TPM 直接关联大模型调用的成本与计费，能支撑用户分组资源管控、定价倍率调整等运营动作，且这两个指标存在联动关系，相同 RPM 下单次请求 Token 消耗越高则TPM越高，相同TPM下RPM越高则单次请求Token 消耗越低。

#### 添加令牌
&emsp;&emsp;用户操作时需先填写基本信息（必填令牌名称、选择令牌分组、设置过期时间并填写新建数量，批量创建会自动添加随机后缀），再配置额度（可设置具体额度及对应等价金额，也能开启无限额度，实际使用受账户余额限制），之后按需设置访问限制（选填模型限制列表、填写IP白名单，注意IP存在伪造风险），最后点击提交完成创建或取消放弃操作，该功能用于管理API调用的权限与资源使用范围。

## 模型广场
&emsp;&emsp;模型广场是Fy-api中集中展示、筛选可用AI 模型的功能界面，支持快速定位不同供应商类型的模型，查看模型参数与计费方式，为后续调用模型提供选择依据。

### 左侧筛选区操作
&emsp;&emsp;通过左侧分类栏可精准筛选目标模型：

- 模型厂商：点击对应供应商（如 Cohere、Google、豆包等），可筛选出该厂商提供的所有模型；
- 标签：选择标签（如 “文生文”“文本嵌入”），可筛选出对应功能类型的模型；
- 可用令牌分组 / 计费类型 / 端点类型：点击对应分类下的选项，可按令牌权限、计费方式、接口端点类型缩小模型范围。

### 顶部操作区操作
- 模型搜索：在搜索框输入模型名称关键词，可快速定位单个模型；
- 功能按钮：点击 “复制” 可复制当前界面的模型信息；
- 切换 “充值价格显示” 可控制是否展示充值关联价格；
- 调整 “倍率” 可查看模型调用的计费倍率；
- 点击 “表格视图” 可切换模型的展示排版形式。

### 模型卡片查看
&emsp;&emsp;界面中的模型卡片展示了模型核心信息：
&emsp;&emsp;包含模型名称、输入 / 输出 token 上限、计费方式（当前均为 “按量计费”）；
&emsp;&emsp;部分模型附带功能说明（如 “Doubao-lite-32k” 标注了轻量版、上下文长度等特性）；
&emsp;&emsp;卡片右上角的选择框可勾选目标模型，用于后续批量操作。

# 用户操作指南
&emsp;&emsp;本流程聚焦普通用户核心操作，涵盖账号登录、令牌管理、API 调用、用量查询及基础问题排查，全程围绕用户日常使用场景，步骤清晰可落地。

## 一、账号登录与基础设置
### 1.1 账号登录
1. 访问平台地址，打开浏览器进入登录页面。
2. 输入账号信息：输入管理员分配的用户名/密码，或通过平台支持的注册渠道（如邮箱）自行登录（具体登录方式以管理员配置为准）。
3. 首次登录验证：若为首次登录，建议修改初始密码，设置含大小写、数字、特殊符号的复杂密码，避免账号泄露。

### 1.2 个人信息完善（可选）
1. 登录后点击页面右上角个人头像，选择「个人中心」或「账号设置」。
2. 补充基础信息：可修改昵称、绑定邮箱/手机号（若平台支持），开启账号安全提醒，便于接收额度不足、令牌过期等通知。

## 二、核心操作：令牌（API Key）管理
令牌是普通用户调用Fy-api接口的核心凭证，需妥善保管，避免泄露给第三方。

### 2.1 新建令牌及分组
1. 进入令牌管理页：登录后在左侧菜单栏找到令牌管理模块，点击进入。
2. 发起新建请求：点击新建令牌按钮，选择令牌分组，令牌关联模型，具体的令牌分组需按实际场景选择（如用户享用豆包系列模型折扣优惠，即可在此处选择豆包模型优惠分组进入配置页面）。
3. 配置令牌参数：
   1. 令牌名称：自定义命名（如“开发测试令牌”“项目A专用令牌”），便于区分不同使用场景。
   2. 有效期设置：可选择「永不过期」或自定义过期时间（如7天、30天），临时使用建议设置短期有效期，提升安全性。
   3. 额度限制：根据管理员分配的总配额，设置该令牌的额度上限（若平台支持单令牌额度管控），避免单令牌过度使用。
   4. 模型权限：勾选可访问的模型（如 GPT-4o、Gemini 等），仅勾选业务所需模型，减少权限冗余。
4. 生成并保存令牌：点击「提交」后，系统会生成一串以“sk-”开头的令牌（API Key），**立即复制并妥善保存**，建议存储在加密文件或密码管理工具中。

### 2.2 令牌编辑与删除
1. 编辑令牌：若需修改令牌名称、有效期、权限，在令牌列表找到对应令牌，点击「编辑」按钮调整参数，保存后立即生效。
2. 删除令牌：当令牌泄露、过期或不再使用时，点击「删除」按钮，确认后该令牌将立即失效，避免被非法调用。若需继续使用，需重新新建令牌。

## 三、API 调用操作（核心环节）
Fy-api已统一各模型接口格式，普通用户无需适配不同模型的原生接口，直接通过平台统一地址调用即可。

### 3.1 调用准备
- 确认接口地址：平台统一调用地址为部署地址+/v1（如 `http://localhost:3000/v1`），具体以管理员告知的地址为准。
- 准备调用工具：可使用 curl 命令、Postman、编程代码（Python/Java 等）、AI 插件（如 VS Code AI 助手）等工具发起请求。
- 明确调用模型：确认已在令牌权限中勾选目标模型，避免因权限不足导致调用失败。

### 3.2 调用步骤（以 curl 命令为例）
1. 构造请求头：必须包含鉴权信息，格式为 `Authorization: Bearer 你的令牌`，同时指定内容类型为 JSON。
2. 构造请求体：按 Fy-api 统一格式填写参数（支持流式/非流式调用），示例如下（以聊天模型为例）：

```bash
curl -X POST http://localhost:3000/v1/chat/completions \
-H "Content-Type: application/json" \
-H "Authorization: Bearer sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
-d '{
 "model": "gpt-4o", # 需与令牌权限中的模型名称一致
 "messages": [
 {"role": "user", "content": "Hello, Fy-api!"}
 ],
 "stream": true, # 流式调用（打字机效果），可选 false
 "temperature": 0.7 # 模型生成随机性，按需调整
}'
